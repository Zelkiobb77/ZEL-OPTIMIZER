</div>⚡ À propos
ZEL OPTIMIZER est une application Windows destinée à simplifier l'analyse de votre PC et la gestion des paramètres système qui peuvent influencer votre expérience en jeu.

Un tableau de bord unique pour consulter votre configuration, sélectionner les actions proposées et examiner leurs résultats. L'objectif est de rendre les réglages plus accessibles, sans promettre de gains de FPS irréalistes.
🧩 Fonctionnalités
Module	Utilité
🖥️ Diagnostic matériel	Informations CPU, GPU, RAM et Windows
⚙️ Profils de configuration	Modes adaptés à différents types de PC
🎮 Paramètres gaming Windows	Vérification et gestion des options prises en charge
⚡ Gestion de l'alimentation	Ajustement des profils disponibles selon la machine
✅ Optimisations sélectionnables	Choix des actions avant exécution
📋 Rapport et historique	Consultation des opérations et de leurs résultats
↩️ Restauration	Retour aux paramètres précédents pour les actions prises en charge


À savoir : certaines options peuvent nécessiter une intervention manuelle, des droits administrateur ou un redémarrage. Les résultats varient selon le matériel, les pilotes, Windows et les jeux.

📥 Téléchargement et utilisation
1. Ouvrez la page des versions officielles.
2. Sélectionnez la version souhaitée, puis, dans Assets, téléchargez ZelOptimizer.exe.
3. Lancez l'exécutable sur Windows 10 ou Windows 11.
4. Analysez votre PC et consultez les réglages proposés.
5. Appliquez uniquement les modifications que vous comprenez et souhaitez utiliser.
6. Consultez le rapport, puis restaurez les modifications si nécessaire.
Téléchargez uniquement depuis ce dépôt officiel. Ne désactivez pas votre antivirus pour installer le logiciel. Si Windows affiche un avertissement, vérifiez l'origine du fichier avant toute décision.
🔎 Transparence et résultats
ZEL OPTIMIZER ne peut pas transformer le matériel de votre PC ni garantir un nombre précis de FPS. Un réglage marqué « appliqué » devrait correspondre à un changement réellement effectué et vérifié ; les réglages non disponibles ou nécessitant une action manuelle doivent être distingués.

Pour évaluer l'effet sur un jeu, comparez les FPS moyens, 1 % low et frametimes, avant/après, dans des conditions identiques.
